Интернет-магазин

## Описание:

Проект "Интернет-магазин" - это веб-приложение на Python для создания и управления продажами товаров с помощью 
интернета. Пользователи могут создавать новые карточки, редактировать их, а также оставлять комментарии к товарам.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:ksucha1894-gif/dz_project_3.git
```

2. Установите зависимости:
```
pip3 install django
pip freeze > requirements.txt
```

3. Создайте базу данных и выполните миграции:
```
python manage.py migrate
```

4. Запустите локальный сервер:
```
python manage.py runserver
```
